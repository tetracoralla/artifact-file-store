# Contributing

Report a concrete use case or a reproducible failure in [issues](https://github.com/tetracoralla/artifact-file-store/issues). Include the package version, runtime, operating system and a minimal example without private data. Small fixes, compatibility reports and improvements to examples are welcome. For larger API changes, describe the user problem before implementing a new abstraction.

Run `npm ci --ignore-scripts` and `npm run check` before proposing a change. Keep public behavior, declarations, examples and regression coverage consistent. Contributions are licensed under Apache-2.0. Maintenance does not promise an external response deadline or acceptance of every proposed feature.
